Turn data into meaningful insights.

The Data Analytics program introduces learners to practical techniques for working with data, from preparing raw information to extracting useful insights.

01

02

03

04

Data Visualization

Present data clearly through meaningful visual representations.

05

Business-Focused Analysis

Use data to understand problems and support practical business decisions.

Build for the modern web.

Learn the foundations of website development and develop practical skills for creating responsive, functional web projects.

WHAT YOU'LL LEARN

The Web Development program introduces learners to the technologies and tools used to design, develop, and manage modern websites.

01

HTML

Build the structure and content of modern websites using HTML.

02

CSS

Style websites and create responsive layouts for different screen sizes.

03

JavaScript

Add functionality and interactive behaviour to web projects.

04

Git & GitHub

Learn version control and manage projects using Git and GitHub.

05

Building Web Projects

Apply your skills by creating practical website projects.
